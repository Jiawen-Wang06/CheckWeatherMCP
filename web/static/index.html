Use your own OpenAI API key

This demo runs on your OpenAI key, so you stay in control of usage and cost. Each message typically costs well under $0.01 with gpt-4o-mini.

🔒 We don't store your key

  • It's kept only in this browser tab and erased when you close the tab.
  • It's sent over HTTPS with each message and used only to call OpenAI for that message.
  • The server never saves, logs or shares it. It isn't even passed to the MCP servers.

Tip: create a dedicated project key with a low spending limit, and revoke it when you're done.

How it works

Browser ──HTTPS──► FastAPI + LangGraph agent (gpt-4o-mini)
                         ├── MCP ──► weather server  (get_weather, get_forecast)
                         └── MCP ──► tasks server    (add_task, list_tasks)
  • Multi-server MCP: one agent loads tools and prompts from two separate MCP servers and combines them in one request.
  • Private by design: bring your own key, isolated temporary sessions, no key storage.
